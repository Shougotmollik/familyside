# Plan: Localize 3 Create Screens

## Goal
Replace all remaining hardcoded strings in the 3 create screens with `loc.translate('key')` calls. These files already import `AppLocalizations` and define `loc` in `build()`, but helper methods and many `Text` widgets still use raw strings.

## Approach
- All 3 files already have `import` and `loc` in `build()` — just need to use it in helper methods
- Each helper method that references `loc` needs `final loc = AppLocalizations.of(context);` at its top
- Snackbar messages in callbacks (like `_submit`) also need `final loc = AppLocalizations.of(context);` since they run outside `build()`
- All keys already exist in both EN and IT localization files — no new keys needed
